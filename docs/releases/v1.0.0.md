# AI Multilingual Platform — Release Notes v1.0.0

**Released:** 2026-08-06  
**Schema target:** 6  
**Tag:** `v1.0.0`

## Summary

First production semantic release of the AI Multilingual Platform: a scoped Gutenberg leaf-translation system with Workspace, TM, Glossary, Review, Background Jobs, rollout/GA controls, REST/CLI/diagnostics, and OpenAI Chat Completions integration.

## Highlights

- Translation Store with UUID block pipeline and render overlays
- Translation Memory with approval-gated write-back (ADR-0015)
- Glossary MVP terminology enforcement
- Review Workflow (submit / approve / reject)
- Background Translation Jobs (Action Scheduler, pause/resume, budgets)
- Limited Rollout + General Availability policy
- Seven supported Gutenberg leaf adapters
- Provider abstraction with OpenAI first (`gpt-5*` / `o`-series temperature compatibility)

## Validation

- OpenAI RC harness `acceptance/rc/v1-openai-rc.php`: **56/56 PASS** against live OpenAI (`gpt-5-mini`)
- Evidence: [V1_RC_OPENAI_VALIDATION.md](../plans/V1_RC_OPENAI_VALIDATION.md)

## Install

Use the production ZIP `ai-multilingual-1.0.0.zip` (no tests, acceptance harnesses, or secrets). Activate on WordPress 6.5+ / PHP 8.1+. Confirm `aiml_db_version` reaches **6** after activation or admin drift migration.

## Known limitations (future enhancements)

Long-term product direction: [POST_V1_PLATFORM_ROADMAP.md](../plans/POST_V1_PLATFORM_ROADMAP.md) (Roadmap v1.0, frozen).

- Elementor body translation not included
- Nested / container block identity not included
- Full WooCommerce surface translation not included
- Render cache remains default-off
- OpenAI uses Chat Completions (not the Responses API endpoint)
- Additional AI providers beyond OpenAI are not shipped
