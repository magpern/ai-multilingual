# Universal Multilingual — Release Notes v1.11.0

**Status:** **DEV / PRE-PRODUCTION RELEASE** — production deployment separately authorized  
**Release version:** 1.11.0  
**Schema target:** **8** (unchanged)  
**Package:** `universal-multilingual-1.11.0.zip`  
**Previous release tag:** `v1.9.0` @ `48f018d6ce10758b72b0203165231c740eb0e6de`  
**Scope audit:** [V1_11_0_DEV_PREPROD_RELEASE.md](V1_11_0_DEV_PREPROD_RELEASE.md)

This release ships **Site Translate — full path** plus all **v1.10.0** preparation content (DeepSeek provider, per-provider AI settings). The `v1.10.0` version was prepared on main but never tagged; operators upgrading from `v1.9.0` receive both trains in this package.

## Highlights

- **Site Translate** in Translator Workspace: coverage-aware picker for pages, posts, and products.
- **Chunked Jobs** (50 objects per job) with shared `batch_id` and Jobs batch focus.
- **Run batch now** enqueues waiting Jobs asynchronously (not synchronous batch translation).
- **Localized URL batch** generate/publish with honest outcomes including `title_stale` and per-item collision recovery.
- **Strategy F selection gate** blocks Gutenberg selections when Strategy F is incomplete; classic-only selections allowed.
- **DeepSeek AI provider** and per-provider generation settings (from the 1.10.0 train).

## Site Translate operator workflow

1. Configure target language (Preview while preparing).
2. Ensure AI / Strategy F as required for Gutenberg content.
3. Segment publication gate ON; auto-publication MANUAL.
4. Select content in **Site Translate** → review coverage → create Jobs → **Run batch now**.
5. Promote language to Published before anonymous acceptance.
6. Manual segment Publish; then enable Localized URLs and generate/publish routes.

See the user manual Site Translate section and [`SITE_TRANSLATE_FULL_PATH_IMPLEMENTATION_PLAN.md`](../plans/SITE_TRANSLATE_FULL_PATH_IMPLEMENTATION_PLAN.md).

## Upgrade notes (1.9.0 → 1.11.0)

1. Install `universal-multilingual-1.11.0.zip` (or use DEV bind mount at this tag).
2. Confirm `aiml_db_version` remains **8**.
3. Rebuild/reload Translator Workspace if not using the packaged `build/` bundle.
4. Review Settings → Automatic translation for migrated OpenAI config; optionally configure DeepSeek.
5. Review Site Translate prerequisites in the user manual before first batch.
