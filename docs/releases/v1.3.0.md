## What v1.3.0 adds

### Operator Translation Lifecycle (Complete)

- **OTL.0–OTL.1** — Operations list, attention filters, and language-scoped operator read models
- **OTL.2** — Unified detail inspector with edit/review and dirty-state honesty
- **OTL.3** — Publication and stale/retranslate workflow wired through TI.7 PublicationService
- **OTL.4** — Bounded Jobs association and Ops→Jobs navigation (Jobs→Ops remains Partial)
- **OTL.5** — Bounded bulk publish / unpublish / enqueue_retranslate (max 50)
- **OTL.6** — ConfirmDialog, centralized dirty-leave admission, session Ops context restore, Review→Ops, bulk→Jobs, a11y/responsive polish, authoritative local Playwright suite

### Foundation retained from v1.2.0

**TIQ Complete (TQ.0–TI.7)** remains the intelligence, QA, assessment, Jobs hardening, and controlled publication foundation. v1.3.0 orchestrates and presents those services; it does not replace them.

## Why it matters

Operators no longer need to stitch Translate, Review, Jobs, and publication explain into an ad-hoc workflow. The lifecycle is coherent: **find → inspect/risk → edit/review → publish → verify/navigation → Jobs/bulk follow-up**.

## Architecture highlights

```
TIQ services (unchanged authority)
  Store / TranslationService
  ADR-0015 review
  TI.4 QA / TI.5 assessment
  TI.6 Jobs
  TI.7 PublicationService
        ↑
OTL presentation + bounded orchestration (Workspace Operations)
```

`approved ≠ published`. `enqueued ≠ translated`. Overlay eligibility ≠ universal frontend visibility proof.

## Upgrade behavior (v1.2.0 → v1.3.0)

1. Install `ai-multilingual-1.3.0.zip` over the previous plugin directory.
2. Activate / visit wp-admin so `maybe_migrate()` runs.
3. Confirm `aiml_db_version` is still **7** (no new migration).
4. Confirm settings remain safe:
   - `segment_publication_gate_enabled` = **false** (default)
   - `auto_publication_mode` = **manual** (default)
5. Open Translator Workspace → Operations and smoke-check list/detail/publish controls.

**Upgrading does NOT start automatic publication, republish existing rows, or clear review state.**

## Known limitations (current)

1. Jobs→Operations reverse deep-link remains **Partial** (no Jobs Store `translation_id` enrichment).
2. Bulk retry-failed remains **Deferred**.
3. Jobs-backed attention remains **Deferred**.
4. Path-B QA/assessment duplication remains **Deferred**.
5. Live Playwright remains **local/non-CI**.
6. Mobile-first admin remains **Deferred**.
7. Selection / bulk-result cross-tab persistence is **Unsupported**.
8. No durable publish-verification product.
9. TIQ carry-forwards: Deferred QA detectors; no RA14 aggregate score; Jobs Outcome B may repeat provider spend; publication gate defaults OFF; automatic unpublish / scheduled publication Deferred.
10. Platform carry-forwards from earlier releases (SEO/Woo/Elementor limits) remain as documented in v1.2.0 scope.
